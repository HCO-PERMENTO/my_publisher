# my_publisher

Et nyt Python-projekt, oprettet fra skabelon.

## Kom i gang

1. Opret og aktiver virtuelt miljø

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Installer udviklingsafhængigheder

   ```powershell
   pip install -e .
   pip install pytest
   ```

3. Kør test

   ```powershell
   pytest
   ```
